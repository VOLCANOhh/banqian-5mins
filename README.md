# 班前五分钟 · Banqian-5min

> 面向建筑工人的个性化安全微培训智能体
> 当天工序 × 个人知识盲区 → 5 分钟语音微培训 → 语音答题判分 → 按遗忘曲线排下次复训

山东大学首届「海之子」杯智能体创新大赛参赛作品。

本仓库为**提交代码包**，内含：微信小程序双端源码、后端编排器源码、部署物料、以及一份可直接手工验证核心机制的测试数据包。

---

## 一、作品简介

**问题**：建筑工地班前教育普遍内容通用、讲完即忘、无法追溯，安全教育与当天实际工序、与每个工人的知识盲区都不挂钩。

**做法**：把「班前五分钟」做成一条可闭环的智能链路 ——

1. 管理员只填当天工序（可手写、可点名到人、可指定班组）；
2. 后端编排器用 LLM 结合规范库（RAG）现场生成一份 4~6 分钟的培训剧本；
3. 工人扫码即学：先朗读今日内容（歌词式滚动字幕），中途听不懂可随时打断提问，回答严格锚定「当日命中集」；
4. 学完自动进入语音答题，按语义判分，答错先追问、再给答案；
5. 成绩与提问记录进入学情库，按遗忘曲线排出下次复训内容，形成个性化闭环。

**AI 能力说明**：特征函数负责给模型规定分析维度、权重与导向（可审计的 trace 证据链），确定性层（调度 / 统计 / 降级）与模糊性层（生成 / 判分 / 答疑 / 追问）分离，第三方服务全部可降级，**演示永不断链**。

## 二、在线 Demo

| 入口 | 地址 | 说明 |
|------|------|------|
| 后端 API（浏览器可直接访问） | `https://api.maomaozhao.cn/` | 返回 `{"ok":true,...}` 与全部端点清单，评审期间持续有效 |
| 微信小程序 | 见提交材料中的体验版小程序码 | 或本地导入 `miniprogram/` 源码运行（见第五节） |
| 零配置演示 | `miniprogram/config.js` 改 `USE_MOCK: true` | 不依赖后端、不依赖任何账号，开发者工具内全流程可点 |

浏览器直接验证（无需任何账号）：

```bash
# 1. 服务健康检查：返回 {"ok":true,...} 与全部端点清单
curl https://api.maomaozhao.cn/

# 2. 身份解析：陌生设备返回 need_bind:true（工人流程无需账号）
curl -X POST https://api.maomaozhao.cn/api/me \
  -H "Content-Type: application/json" -d "{\"dev_id\":\"demo-visitor\"}"

# 3. 天气感知（未配置和风天气时返回 source:"stub" 的演示数据，验证"降级不断链"）
curl -X POST https://api.maomaozhao.cn/api/weather \
  -H "Content-Type: application/json" \
  -d "{\"lat\":36.65,\"lng\":117.12}"
```

> 在 Windows PowerShell 下，第 2、3 条里带 `{\"...\"}` 的 `-d` 需写成 `-d '{\"...\"}'`（5.1 会吞掉传给原生程序的内层双引号）。第 1 条不受影响。

> **管理端接口需要管理员身份**：`/api/admin/*`、`/api/workers`、`/api/tasks`、`/api/groups`、`/api/content/list` 等在服务端按 openid 鉴权，未激活的管理员身份调用会返回 `{"error":"forbidden: admin only"}`，这是设计如此。评委查看管理端请走第一节的 `USE_MOCK: true` 离线模式，无需账号即可看到完整三界面。

## 三、运行环境

| 组件 | 要求 | 说明 |
|------|------|------|
| 后端 | Node.js 18+ | 零第三方 npm 依赖，仅用内置 `http` / `https` / `zlib` / `fs` / `path`；线上实测运行于 Node v18.19.1 |
| 前端 | 微信开发者工具 Stable 版 | 基础库 3.8+ |
| 操作系统 | Windows / macOS / Linux 均可 | 小程序端需开发者工具；后端纯 Node，跨平台 |
| 部署（可选） | Ubuntu + nginx + certbot | `server/deploy/` 内含 systemd 服务、nginx 配置、部署与自检脚本 |

## 四、依赖要求

- **后端零依赖**：不需要 `npm install`，仓库内不含 `node_modules`，`package.json` 无任何 `dependencies`。
- **小程序零依赖**：不引入第三方小程序组件库，图表 / 二维码 / 语音均为仓库内自带实现。
- **外部平台为可选项**：微信、阿里云语音、LLM、和风天气**均非运行必需**，未配置时自动降级为桩实现或内置种子数据，全流程仍可演示。

## 五、安装启动步骤

### 5.1 后端

```bash
git clone https://github.com/VOLCANOhh/banqian-5mins.git
cd banqian-5min/server
node index.js        # 默认监听 :3000，可用 PORT 修改
```

验证：

```bash
curl http://127.0.0.1:3000/
# 返回 {"ok":true,"name":"banqian-5min-server",...}
```

如需接入真实微信 / 语音 / LLM / 天气，复制根目录 `.env.example` 为 `.env` 并按提示填写（也可用 systemd `Environment=` 注入，见 `server/deploy/deploy.md`）。**不配置任何变量同样可以启动并演示。**

运行时数据写在 `server/store.json`（首次启动自动用内置种子数据初始化，无需手工准备）。

### 5.2 微信小程序

1. 微信开发者工具 → **导入项目** → 选择 `miniprogram/` 目录（`project.config.json` 已自带配置）；
2. 详情 → 本地设置 → 勾选「不校验合法域名」（本地联调期）；
3. 按需修改 `miniprogram/config.js`：

```js
API_BASE: 'https://api.maomaozhao.cn',  // 后端地址
USE_MOCK: true,                         // true = 内置种子数据离线跑通；false = 调真实接口
MOCK_ROLE: 'admin',                     // 'admin' 管理端三界面；'worker' 工人学习流
```

4. 编译运行即可。

## 六、测试账号与基础数据

**不需要申请任何账号即可完整测试**，三种方式任选：

1. **离线 mock 模式（推荐评委用）**：`USE_MOCK: true`，小程序内置 12 名工人 / 3 个分组 / 8 条规范库与预置内容库、确定性学习数据，任意日期可回看，管理端与工人端全流程可点。
2. **真实后端 + 在线 Demo**：`USE_MOCK: false` 且 `API_BASE` 指向 `https://api.maomaozhao.cn`，用浏览器直接调接口验证（见第二节）。
3. **手工跑机制数据包**：[`mock-数据包-手工跑机制.md`](mock-数据包-手工跑机制.md) —— 一份不依赖任何代码即可验证核心机制的原始数据包，包含 1 个真实工地场景、18 条逐字规范条文（附文号与出处）、RAG 检索模拟打分表、剧本题目与期望要点、工人语音回答样本（含方言噪声）、打断提问样本、语音指令样本、学情档案输入，以及真实晨会喊话对照锚。

管理员身份在真实模式下按 `ADMIN_OPENIDS` 白名单判定；工人身份走绑定码 / 小程序码。**体验用白名单与绑定码见提交材料，或联系项目组开通。**

## 七、核心功能操作说明

### 工人端（约 5 分钟一条完整链路）

1. 扫工地门口码 / 输入绑定码 → 绑定到自己的工人档案 → 品牌页；
2. 自动朗读今日学习内容，字幕随语音滚动（歌词式）；
3. 中途没听懂 → 点「没听懂?」打断提问 → 后端按**当日命中集**作答 → 答完回到被打断的那一步继续；
4. 学完自动读题 → 按住说话答题（支持方言识别）→ 判分；
5. 答错先追问一层再给正确答案；答对也按情况追问；
6. 成绩页：得分 + 「今日已完成」印章 + 下次复训日期；
7. 语音指令：暂停 / 继续 / 重听 / 下一题 / 大点声等。

### 管理端（同一小程序，按身份自动分流，底部三个界面）

| 界面 | 能做什么 |
|------|---------|
| **推送** | 推送记录按日期分组展示 → 「＋添加今日推送」→ 先选人（全部 / 分组 / 个人）→ 顶部 **AI 预测推荐**（谁逾期、为什么）→ 选内容（点标题查看 **AI 剧本预览**：六角色 trace + 剧本正文）→ 推送 |
| **学习情况** | 姓名检索；今天（未学置顶 + 一键提醒）/ 往期（日期检索）；点工人卡片进详情：薄弱点掌握度、行为诊断、复训计划、错题记录 |
| **工人** | 分组管理、工人档案、规范表单录入（手机号脱敏）、生成 / 作废工人绑定码 |

## 八、注意事项

1. `USE_MOCK` 与真实模式共用同一份接口契约（`miniprogram/PROTOCOL.md`），切换只改一个开关。
2. 工人手机号在所有接口均为脱敏下发（如 `138****0001`）；管理端接口在服务端按 openid 鉴权，非白名单返回 403。
3. `server/store.json` 是运行时数据文件，含 openid 等真实标识，**请勿提交到公开仓库**（`.gitignore` 已排除）。仓库内不含任何真实密钥，全部走环境变量。
4. 学习档案仅用于技能成长，不作绩效考核依据。
5. 部署到自有域名后，需在微信公众平台配置 request 合法域名，并同步修改 `miniprogram/config.js` 的 `API_BASE`。
6. 语音朗读与识别依赖微信同层播放与录音能力，建议在真机上体验完整语音流程；开发者工具中可用 mock 模式走通逻辑。

## 九、第三方平台与服务（如实注明）

| 类别 | 第三方 | 用途 | 是否必需 |
|------|--------|------|---------|
| 平台 | 微信公众平台 | 登录换 openid（`jscode2session`）、生成小程序码（`wxacode`） | 否，未配置降级为 `dev_id` 身份 |
| 语音 | 阿里云智能语音交互 NLS | 一句话识别（按工人方言选 appkey）、语音合成 TTS | 否，未配置降级为桩 / 前端兜底 |
| 大模型 | OpenAI 兼容 LLM API（当前接入 DeepSeek，默认 `https://api.deepseek.com` / `deepseek-chat`，支持三通道降级） | 工序解析、剧本生成、语义判分、追问、答疑 | 否，未配置降级为预置剧本 + 规则判分 |
| 天气 | 和风天气 QWeather | 气象风险感知（大风等对工序安全的影响提示） | 否，未配置返回演示天气并标注 `source:"stub"` |
| 证书 | Let's Encrypt（certbot） | HTTPS 证书与自动续期 | 否，仅影响线上部署 |
| 数据库 | 无 | 使用 JSON 文件持久化（`server/store.json`），单文件零运维 | — |

后端代码不内置任何第三方密钥，全部通过环境变量注入：

| 变量 | 用途 |
|------|------|
| `WX_APPID` / `WX_SECRET` | 微信服务端接口 |
| `ADMIN_OPENIDS` / `ADMIN_QR_KEY` | 管理员白名单与管理员码防伪 key |
| `NLS_APPKEY` / `ALI_AK_ID` / `ALI_AK_SECRET` | 阿里云语音识别与合成 |
| `LLM_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | LLM 主通道（`_2` / `_3` 后缀为备用通道） |
| `QWEATHER_KEY` / `QWEATHER_HOST` | 和风天气 |
| `PORT` | 后端端口，默认 3000 |
| `SSHPASS` | 仅本地部署脚本使用 |
